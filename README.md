# ApexPlanet Software Pvt. Ltd. – Data Analytics Internship

## About the Internship

This repository contains my work, projects, and practical assignments completed as part of my **Data Analytics Internship at ApexPlanet Software Pvt. Ltd.**

The internship focuses on developing practical data analytics skills through hands-on tasks involving data exploration, data cleaning, transformation, analysis, and visualization.

Throughout this internship, I aim to apply Python and data analytics concepts to real-world datasets and develop skills in extracting meaningful insights from data.
